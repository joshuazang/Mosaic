# Mosaic has moved

> **Development and releases have moved to
> [joshuazang/IM-style-editor](https://github.com/joshuazang/IM-style-editor).**
> This standalone repository is retired. It will receive no further code,
> builds or releases.

Mosaic and IM-style-editor now share one repository and one core. They remain
two separately installable Standard Notes interfaces for the same format-3
notes. All future work on either interface happens in **IM-style-editor**.

- **[Current source and guide](https://github.com/joshuazang/IM-style-editor/tree/main/mosaic)**
- **[Current install manifest](https://joshuazang.github.io/IM-style-editor/mosaic.ext.json)**
- **[Current preview](https://joshuazang.github.io/IM-style-editor/mosaic/index.html?preview=1)**
- **[Issues and feature requests](https://github.com/joshuazang/IM-style-editor/issues)**
- [Shared maintenance](https://github.com/joshuazang/IM-style-editor/blob/main/docs/shared-editors.md)
- [Security boundaries](https://github.com/joshuazang/IM-style-editor/blob/main/docs/editor-security.md)

This repository keeps its commit history, release tags, downloads and GitHub
Pages files so old links remain available. Its final 1.0.3 manifest preserves
the Mosaic plugin identifier and points `latest_url` to IM-style-editor for
subsequent updates. The old manifest, preview and download snapshots are frozen;
use the current links above for new installations and releases.

`source.json` identifies the source commit for the final static build kept here.
